Pequeños Sabores

Este proyecto es un trabajo integrador de la materia Programación Web 1.

Pequeños Sabores es una página web sobre alimentación complementaria para bebés. La idea es compartir información sobre las distintas etapas, algunos consejos y recetas sencillas para acompañar su crecimiento.

Páginas del sitio

Inicio: presentación del sitio y carrusel de imágenes.

Etapas y Recetas: información sobre las etapas de alimentación y algunas recetas.

Contacto: formulario para enviar consultas, con validaciones.
